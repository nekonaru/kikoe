# Project

- PROJECT_NAME: Kikoe
- PROJECT_KIND: app
- PIPELINE: pr
- LICENSE: MIT
- Repository: https://github.com/nekonaru/kikoe.git

Kikoe is a free, unlimited, offline audio/video transcription app built on
whisper.cpp. One C++ core, exposed through a C API, shared by the CLI, the
desktop app (Flutter), and the Android app (Flutter + Dart FFI).

User-facing language: English is the source for all copy; Indonesian is the
translation (README.id.md, CHANGELOG.id.md, UI strings).
